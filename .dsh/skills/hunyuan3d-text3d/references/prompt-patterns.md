# 提示词模板与分品类写法

配合主 `SKILL.md` 的「提示词方法论」使用。所有模板都遵循
**主体 + 风格 + 材质 + 背景 + 无文字** 的结构。

## 通用骨架

```
一个<风格>的<主体>，<材质/颜色>，<背景>，无文字
```

风格词建议只用一个：`低多边形` / `卡通` / `写实` / `手绘` / `赛博朋克` / `蒸汽朋克`。

## 角色 / 生物

形体越"块面"越好。避开毛发、飘带、细长四肢的复杂姿态。

- 一个卡通风格的圆润柯基犬坐姿，橙白配色，白色背景，无文字
- 一个低多边形的骑士人偶，银灰盔甲，站姿，白色背景，无文字
- 一只写实风格的猫头鹰，棕色羽毛，停栖姿态，白色背景，无文字

角色要绑定/摆姿势时加 `apose: true`。

**避开**：毛皮细节、飘动的披风与头发、手指分节、大量薄片鳞甲。

## 道具 / 硬表面

3D 生成表现最好的品类。CAD 类、器皿、武器、家具都合适。

- 一个低多边形风格的木质小台灯，暖色灯罩，白色背景，无文字
- 一个蒸汽朋克风格的黄铜齿轮怀表，做旧金属，白色背景，无文字
- 一个卡通风格的红白蘑菇，圆润伞盖，白色背景，无文字
- 一个陶瓷质感的青花瓷茶壶，蓝白纹样，白色背景，无文字

**避开**：链条、镂空花纹、齿轮咬合的复杂装配、极薄的刀锋。

## 场景 / 建筑

单体建筑效果好；复杂场景建议拆成多个单体分别生成。

- 一个低多边形风格的木屋，红色屋顶，白色背景，无文字
- 一个卡通风格的灯塔，红白条纹，白色背景，无文字
- 一个写实风格的石头喷泉，青苔点缀，白色背景，无文字

**避开**：整条街道、远景环境、植被繁茂的自然地貌。

## 抽象 / 图标

- 一个低多边形的紫色小火箭，圆润造型，白色背景，无文字
- 一个卡通风格的黄色星星，圆角，白色背景，无文字

## 反例（会导致糊面或杂物）

| 反例 | 问题 |
|------|------|
| "一只猫和一张桌子" | 多主体融合 |
| "一座繁华的城市" | 尺度过大、细节无法解析 |
| "带精美镂空花纹的灯笼" | 镂空易成破面 |
| "一个写着 LOVE 的杯子" | 文字会被建模成凸起噪点 |
| "非常艺术化、很有设计感的台灯" | 无具体形体指向 |
| "低多边形+写实+赛博朋克风格" | 风格冲突 |

## 迭代示例（修"糊成一团"）

1. 初版：`一个台灯` → 得到一团不规则块体
2. 加主体+风格：`一个低多边形风格的台灯，白色背景，无文字` → 有灯形但表面杂乱
3. 加材质+细化：`一个低多边形风格的木质小台灯，暖色灯罩，白色背景，无文字` → 可用
4. 若细节不足：同一提示词提高 `faceCount`

**每次只改一处**，否则无法判断是哪个改动起了作用。
